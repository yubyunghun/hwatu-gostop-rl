# web

React + TypeScript + Vite frontend for the Go-Stop project. See the [project
README](../README.md) for the full picture (architecture, RL results, how to run everything
together).

```
npm install
npm run dev      # requires the API running at http://localhost:8000 (or set VITE_API_URL)
npm run build    # type-checks (tsc -b) then builds
```
